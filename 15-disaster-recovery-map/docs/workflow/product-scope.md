# 首版产品范围

更新：2026-08-29。下列内容只覆盖当前工程已实现或已明确排除的行为。

| 项 | 已确认 |
| --- | --- |
| 首版主题 | 暴雨云团、台风外雨带、山洪水迹、潮汐变化 |
| 地区 | 不采集真实地点；地点为用户可选的本机文字 |
| 主要用户 | 想留下一次自然目击记录的个人 |
| 核心场景 | 用内置示例照片确认现象类型并保存在本机 |
| 来源分级 | 本版只产生「未核验公众线索」；权威发布与已核验协作信息不生成 |
| 首版功能 | 示例记录、本机列表、清除、科普短文、隐私说明、系统电话入口 |
| 非目标 | 相机/识别/定位/账号/同步/应急指挥/影响范围图 |
| 错误处置 | 存储失败可重试；无法打开系统电话时提示改用系统电话应用 |
| 隐私 | 同意后才读写观察记录；可选地点与备注仅存本机 |
| 待核验 | Unsplash 正式发布署名方式、商店主体、公开隐私政策 URL |
| 成功指标 | 用户能区分线索与事实，并能删除本机记录 |
