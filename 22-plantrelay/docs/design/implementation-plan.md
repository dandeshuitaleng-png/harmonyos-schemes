# 叶伴 UIUX 重构实施约定

2026-09-07 · 用户授权原生界面重构：趣味、3D 卡通、可玩可交互。

## 用户路径与层级

`pages/Index` 保留唯一入口。花园 / 交接 / 足迹为三个本机视图；新增 / 完成 / 摘要 / 关于为可返回的全页表单。首页顺序为品牌栏、花园标题、软陶盆栽与状态、当前卡任务主操作、交接卡选择和进度。唯一主要下一步是空态新建卡、待接手确认、已接手记录完成之一。新增表单按需打开，展示昵称、房间、任务与照护人可见标签；不预填植物或照护内容。

## 视觉与组件

使用已映射 color.json 的奶油底、森林绿按钮、鼠尾草舞台、赤陶/淡紫点缀。32/24/20fp 标题、16fp 正文、14fp 标签；16/24vp 页面间距、24/32vp 卡片圆角。`ClayPlant` 是原生 Canvas 渐变、立体软阴影、厚盆沿、叶片高光和笑脸，点击产生一次摇摆、表情与反馈，不写交接状态。配色选项为陶土/鼠尾草/淡紫，写入当前卡的可选 palette 属性；空态与创建表单仅改草稿。完成写入成功后才庆祝。自绘 SVG 统一 24vp 线性导航图标。

## 状态与数据

继续读写 Preferences 的 `leafmate/cards`；兼容原字段并加 palette 默认 0。原卡是任务卡，统计称交接卡，不能直接称植物数量。加载失败禁止新增/确认/完成/换色保存，提供重试；写入失败保持旧列表与输入。空集合不注入样例。筛选为空提供切回全部。摘要有字段选项、照护人和备注默认隐藏、可取消、仅预览。没有照片/提醒/网络流程，因此无新增权限请求；离线走同一路径。

## 适配与验证

页面由可滚动内容与独立底栏组成，表单无底栏遮挡。宽度限制 760vp，手机边距 20vp；横屏和平板保持优先级。正文可换行，按钮用最小 48vp 高度，主要操作不使用仅图标。新增和完成输入都能在键盘出现后滚动。系统返回优先退出子表单，保存中保护当前操作。深浅色使用真实资源映射。接入系统 API 23 减少动态状态并提供手动开关；无循环装饰动画。

验证应覆盖空态、创建、接手、完成、足迹、配色、摘要、取消、异常恢复、大小屏与深色。仅构建不算视觉/设备通过；DevEco 原生 Previewer 图像单独记为 Previewer 证据，持久化、读屏和设备验收仍需设备。
