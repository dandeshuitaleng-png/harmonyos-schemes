# 修物志 · 本机设备卡

离线单列页面依次呈现数据边界、设备表单和本机列表。每张设备卡可展开本机维修事件表单：用户填写事件类型、发生日期和可选备注后保存，随后按新到旧显示在该卡的时间线中。事件完全依附于已有设备卡；尚未发生事件时明确显示“尚未记录维修事件”，不把空白伪装为维修完成。保存失败时保留输入内容并提供“再次保存该维修事件”，读取失败可重试本机读取；必填信息不足时按钮禁用。卡片还可打开导出前的本地字段选择：类别、购买日期默认包含，用户填写型号默认隐藏，保修日期和事件/备注仅在存在时可选；零字段显示明确提示，取消只退出选择且不保存。该流程只形成屏幕内摘要，绝不生成文件、调用分享或导出 API。文件 Picker、失效 URI、附件、真实导出、诊断、报价与网络在对应真实能力接入时再实现。手机/平板使用可滚动单列，动作均有文字说明，不只依赖颜色表达状态。
