# TideWatch · 离线观察草稿

> Route: `pages/Index` · Status: Scoped · Updated: 2026-08-29

## 本轮垂直切片

- 用户目标：巡查时先把一条带采集时间、来源与有效期的观察保存为本机草稿。
- 主操作：创建一条本地「待审核」观察草稿。
- 对外边界：草稿绝不等于预报、公告或灾情结论；不公开、不上传、不可供居民查看。
- 本轮不接入：相机、定位、离线地图、蓝牙、网络、审核服务或居民端。

## 信息层级

1. 危险边界：遇紧急情况使用官方渠道。
2. 来源要求：每条本地草稿显示来源标签、采集时间、有效期和待审核状态。
3. 主操作：创建本机草稿。
4. 本机草稿列表：仅显示待审核，不向居民公开。

## 状态与验收

| 状态 | 内容 | 恢复 |
| --- | --- | --- |
| Loading | 读取本机草稿 | 自动完成 |
| Empty | 未创建草稿 | 创建本机草稿 |
| Success | 待审核草稿与来源字段 | 可继续离线保存 |
| Error | 本地存储失败，不上传 | 重试读取 |

验收依赖：构建通过；真机上创建、重启恢复、深浅色与平板布局需在调试签名后实际验证。
