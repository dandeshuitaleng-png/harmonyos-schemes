# QuietBeacon · 本机求助卡

> Route: `pages/Index` · Status: Implemented · Updated: 2026-08-28

用户在不便语音表达时，三步内选择、生成并取消一张本机求助卡。主操作是生成卡片；不会发送短信、读取联系人/位置、报警或后台追踪。

页面按「安全边界 → 模板 → 主操作 → 当前卡或空态 → 错误重试」排序；单列可滚动，平板不隐藏操作，深浅色均映射到 `app.color`。本机 Preferences 首次读取、创建和取消后均立即 `flush`。

| 状态 | 内容与恢复 |
| --- | --- |
| Loading | 读取本机状态，自动完成 |
| Empty | 选择模板并生成 |
| Success | 显示未发送的本机卡，可取消 |
| Error | 明确未发送，提供重试 |

验收：首次空态、创建、取消、重启恢复；所有按钮为完整文本，状态不用颜色单独表达。
