# SCR-01: 近地天体离线学习卡

> Route/entry: `pages/Index` · Status: Implemented（离线会话学习） · Updated: 2026-08-31

- 用户目标：理解近地天体的基础概念，而非获取实时风险判断。
- 主操作：选择一张学习卡，再完成一题自检。
- 状态：初始、阅读、自检正确、自检需复习；答对可进入循环的下一张卡并清空作答，答错可清空作答后重新阅读当前卡；无加载/权限状态，因为本轮无网络和权限。
- 无障碍：题目、选项、当前卡和反馈动作均用文字说明；顺序为范围提示、卡片、问题、反馈、下一张或重新阅读。
- 适配：手机单列滚动；平板限宽并保留同一优先级；文本可换行。
