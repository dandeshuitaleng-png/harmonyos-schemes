# UI U1 · v0.2.0

继承现有docs/design/MASTER.md的原生观察簿规范，当前版本不重建界面。
目标用户沿海巡查员；优先记录事实和时间，避免让风险判断看起来是官方公告。

线框：隐私说明→观察簿（标题/边界提示/新建/查询筛选/卡片/隐私设置）→表单（类型/标题/地点/描述/风险/有效期/保存/取消）→观察簿。删除确认在对应卡片；清空确认在列表末尾。

设计变量：明/暗依次列出；surface_canvas #F2FAFB/#0D1D20；surface_card #FFFFFF/#162A2E；action_primary #087E8B/#62CED8；text_on_primary #FFFFFF/#082023；text_primary #16343A/#E6F7F8；text_secondary #3D585C/#B5CED1；text_danger #8B1E1E/#FFB4A8。其他语义值继承base/dark color.json。
系统字体；标题30/24/20fp，正文16fp，时间14fp；行高22–26；页面20vp、卡片18vp留白，间隔8–16vp，最大宽640vp，卡片圆角16vp；无新增阴影/动画/图标资源，无网络字体。

UI-001（AC-006）：1256×2760 API24手机模拟器默认缩放，浅/深色文字、长标题、按钮无重叠溢出，截图核对上述变量。平板/物理设备/读屏正式认证属于后续验收，不能声称本轮覆盖。
UI-002（AC-006）：真实保存后反馈；加载/忙碌禁用冲突操作；迁移失败显示文字原因和重试入口，无虚构示例。空数据与筛选空态区别保留。
UI-003（AC-006）：触控按钮≥48vp，输入有名称，错误文字不只靠颜色，系统返回保留确认；检查焦点进入输入框、软键盘输入和返回路径。外接键盘/读屏系统矩阵不在本轮设备范围。
UI-004（AC-003/006）：升级不增加用户操作，不显示“上传/已审核”；隐私说明解释自动迁移、验证后清理旧副本；拒绝同意不初始化数据库。
