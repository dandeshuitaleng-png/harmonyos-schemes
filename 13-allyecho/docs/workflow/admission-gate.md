# 共情回声 · 实施门禁

更新：2026-08-29。

## 本轮核对

- 本机 SDK 类型声明未发现可直接验证、可用于文本卡片的系统分享调用契约；不能以预览页代替系统分享，也不能宣称内容已发送。
- “危机词触发当地资源”需要用户所在地区和经过核验的资源清单；当前没有这些数据，不能编造热线或入口。
- 用户感受卡属于敏感内容。若进入实现，必须明确草稿留存、删除、系统分享前的内容/收件人确认，以及分享失败时内容是否仍留在本机。

## 当前结论

本轮不建立聊天、陌生人匹配、公开动态或本地敏感卡片库。待系统分享 API 在目标 SDK/真机被验证，且地区资源清单获确认后，再实现本机编写、预览、删除与显式分享确认流程。
