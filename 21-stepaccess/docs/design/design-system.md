# 步道通 · 最小设计系统

> 版本：0.1 · 更新：2026-08-30 · 状态：骨架实现

## 目标与原则

- 主要用户：轮椅、助行器、婴儿车和低视力出行者，以及陪同记录者。
- 核心任务：用三个明确选择创建一条本人当下的步道通行观察。
- 唯一主操作：`创建当前会话观察`。
- 信任边界：页面首屏持续显示“个人观察 · 未经审核”；不把个人感受写成认证、路线安全或普遍结论。
- 内容密度：单列滚动；先说明边界，再依次选择障碍、出行情境与通行感受。

## 语义资源

| 角色 | 资源 | 用途 |
| --- | --- | --- |
| 页面 / 卡片 | `surface_canvas` / `surface_card` | 页面底色和信息分组 |
| 控件 / 选中 | `surface_control` / `surface_selected` | 普通选择与选中反馈 |
| 警示 / 成功 | `surface_warning` / `surface_success` | 未审核边界与当前会话结果 |
| 主 / 次文字 | `text_primary` / `text_secondary` | 标题、正文与辅助说明 |
| 警示 / 成功文字 | `text_warning` / `text_success` | 与文字状态一起使用，不单靠颜色 |
| 主操作 | `action_primary` / `text_on_primary` | 创建观察按钮 |

Light 与 Dark 均映射到 `entry/src/main/resources` 的实际颜色资源。字号使用 30 / 20 / 17 / 15 / 14 vp 级别；触控控件高度不低于 48 vp；间距以 6 / 8 / 10 / 16 / 20 vp 为主，卡片圆角 20 vp。

## 组件、适配与无障碍

- 选择按钮在文字中追加“已选择”，避免只依赖底色；每个按钮设置完整读屏文本。
- 未完成三个选择时，主按钮禁用，并在按钮前说明恢复动作。
- 创建后出现“仅自己可见 · 当前会话”和删除入口；删除会清空三个选择。
- 手机和平板共享同一信息优先级；当前骨架用单列 `Scroll`，避免大字号时固定高度裁切。
- 当前无异步、网络、存储或权限请求，因此没有加载、网络错误或权限拒绝运行态；这些状态应在对应真实能力加入时一并设计与实现。
- 源码层只能确认语义与布局意图；读屏、150% 字号、Dark、手机和平板视觉仍需真实运行验证。
