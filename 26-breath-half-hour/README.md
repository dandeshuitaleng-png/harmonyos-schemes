# 喘息半小时

HarmonyOS first MVP for creating a clear 30-minute relief request with Mock trusted contacts and request templates.

## MVP scope

- Home page with project positioning, primary action, recent Mock records, and local-data boundary copy.
- Relief request creation page with Mock contacts, request templates, time window, optional note, and local draft action.
- No login, backend, cloud sync, AI, payment, persistence, detail page, delete flow, or official-service claims.
