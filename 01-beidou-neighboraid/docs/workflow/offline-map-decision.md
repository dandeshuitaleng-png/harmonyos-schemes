# 01 北斗邻援：离线地图与演练包决策门禁

> 状态：等待产品与授权决策。更新时间：2026-08-31。

## 已确认

- 当前工程仅有本地演练记录和两种内置演练提示；它们明确**不是**地图下载或应急指引。
- 工程没有地图数据文件、地图 SDK、网络服务、下载协议、目标地区，或可复用的地图许可证。
- `AGENTS.md` 要求首版能够下载一块离线地图和演练包，但也要求先验证真实 API 能力，不能把任意设备或资料伪装成已获支持的能力。

## 当前技术核查（2026-08-31）

- 华为官方的 [Map Kit](https://developer.huawei.com/consumer/en/hms/huawei-MapKit) 页面确认 HarmonyOS 支持原生地图展示与交互；这可以作为后续地图呈现候选，但该页面没有证明本项目可离线分区下载、缓存或再分发地图数据。
- 当前本机 DevEco SDK 的 phone/tablet system capability 清单包含 `SystemCapability.Map.Core.OfflineMapData`，但在已安装 ArkTS Map Kit 声明中没有找到可直接接入的 `offlineMapData` 模块或下载接口声明。此为“能力待真机/API 版本验证”，不是可交付的离线地图方案。
- 旧版 HMS Map Kit codelab 要求 AppGallery Connect 配置、签名指纹和网络权限，且其说明只覆盖地图显示/交互；不能据此推断它符合本项目的离线优先和无网络初始切片。[官方 codelab](https://developer.huawei.com/consumer/en/codelab/HMSMapKit-HarmonyOS/)

## 不能自行假定的事项

- 地图数据源及其离线缓存、再分发、商用和署名权限。
- 首个覆盖区域、缩放等级、包大小上限、更新频率和断网后的保留策略。
- 用户是否允许联网下载、是否只允许预装包，以及删除本地地图包的恢复路径。
- 与地图关联的位置精度、按需定位权限与隐私说明。

## 需要用户确认的一项产品决策

为 01 指定**首个离线地图数据源及其覆盖范围**。确认后才可开展：许可证留档、包格式/大小限制、原生下载与本地分区存储、下载失败/空间不足/删除恢复状态和真机验收。

## 在决策前可继续的工作

- 继续维护不依赖地图、网络或签名材料的本机事件与演练包路径。
- 不宣称离线地图、位置、近场交换、加密摘要、上传或审核端已可用。
