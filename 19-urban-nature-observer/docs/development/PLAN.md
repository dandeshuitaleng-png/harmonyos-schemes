# 19号城市自然观察：开发完善方案

制定：2026-09-20；实现与验证续办：2026-09-21。基线提交：d05b4aa0aa1beaa0c3910eadddc9b3a2b7b257cf。

## 目标与范围

为城市青年和亲子家庭提供“发现—记录—理解—回访”的植物特征观察闭环。沿用不绑定城市的首版设定：公园、街边、校园、社区，仅记录粗略环境。一次选择叶缘、叶脉、花果或树皮之一，不推断物种、健康或生态结论。

本轮完成离线本机记录 MVP：用户主动保存、重启恢复、历史回顾、再次观察、逐条确认删除与清空。照片、定位、网络、账号、社区及自动识别不纳入此次实现。保存只发生于用户点击；未保存草稿退出后丢弃；设备应用沙箱内保留最近至多10条，达到上限时提示先删除，绝不自动淘汰。删除成功必须等磁盘写入完成；不提供云备份、同步或导出。卸载/清除应用数据后记录不可恢复，不承诺系统级备份行为。

## 基线问题

1. 所有状态在页面内，关闭应用丢失。
2. “暂时看不清”与确定观察可同时选择；花果“未见”与“看到”冲突。
3. 回顾卡依赖正在编辑的表单，没有独立的记录快照。
4. 持久化、存储失败与损坏数据没有处理或验证证据。
5. 文档引用的 `.cursor/skills/harmonyos-scheme-ui/SKILL.md` 未随仓库提供，本地未找到。沿用现有 MASTER 和资源，不开展新的设计系统生成。

## 交互与内容规则

- “暂时看不清”与同任务其他项互斥；“未见花果”与花/果互斥。
- 保存生成独立快照；重复点击及异步处理中操作禁用，保存成功清空本次特征。
- 每条显示“个人观察，未鉴定”、任务、环境、时间及所见；再次观察沿用任务/环境，重新勾选，不覆盖旧记录。
- 删除明确目标并二次确认；返回键首先取消删除确认。
- 提示只引导肉眼观察，不编造物种资料或声称教育效果。激励采用具体记录与回访，不设签到、排行榜。
- 沿用绿色语义颜色和暗色资源、48vp触摸区、可换行文字及读屏标签。

## 验证矩阵

自动化：四类选项、非法任务/环境/特征、互斥双向切换、取消选中、序列化恢复、损坏/未来版本、重复 ID、数量上限、保存/删除写失败回滚。

设备：首次空状态 → 选择任务/环境/特征 → 保存 → 强制结束进程再打开 → 回顾 → 再次观察 → 取消删除/确认删除 → 再次重启确认删除生效。补测10条上限、全部删除、快速连点、返回键、浅/深色、手机/平板、放大字体和读屏。真实设备证据与编译证据分开记录。

可用性：邀请5名新手在3种真实植物情境完成任务；目标至少4人5分钟内完成，全部能说清观察并非鉴定、能找到删除入口。此处是待验证目标，不是已取得结果。

发布前：Debug/Release签名、设备验收、商店主体、隐私页面与截图。没有凭据或设备时明确记录阻塞，不复用其他项目签名，也不把未签名HAP当成可发布版本。
