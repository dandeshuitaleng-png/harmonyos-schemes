# 城市自然观察 · 首版产品规格

更新：2026-09-21。

## 首版定义

- 用户：希望认识周边植物的城市青年与亲子家庭。
- 地区：不绑定城市；首版不收集精确地点，只允许用户选择“公园、街边、校园、社区”四类粗略环境。
- 单一主题：城市常见植物的形态观察，不进行物种识别。
- 价值主张：用一项可完成的观察任务，让用户记录可见特征并理解“观察不是鉴定”。

## 核心闭环

发现一株植物 → 选择观察任务（叶缘、叶脉、花果、树皮之一） → 勾选肉眼可见的特征 → 阅读通用观察提示 → 本机回顾或删除。

### 当前本地实现边界（2026-09-21）

- 四类观察任务、粗略环境、多选可见特征与任务提示；不输出物种或健康结论。
- 用户点击保存后，保存独立快照到 Preferences，并等待 flush 成功。历史按最新在前显示，可重启恢复、再次观察、逐条删除或清空。
- 本机最多10条，满额阻止新保存并提示先删除；不自动清除记录，不持久化未保存草稿。
- “暂时看不清”与确定特征互斥；“未见花果”与看见花/果互斥。切换任务清空特征。
- 删除须二次确认；返回键先取消确认。存储失败保留草稿/原列表并尝试回滚；回滚失败进入只读并要求重新启动核对。损坏/未知版本数据禁止覆盖。
- 不拍照、定位、上传、识别、接入社区或地图。不提供导出或云备份。卸载或清除应用数据后记录不可恢复。
- 保留/删除语义已在本轮开发方案中明确；用户授权“根据方案进行完善”覆盖本轮离线实现。

## 功能与非目标

| 首版功能 | 规则 |
| --- | --- |
| 受控观察任务 | 一次只做一种特征，不输出物种候选 |
| 粗略环境 | 不使用定位，不记录敏感或稀有物种地点 |
| 本机记录 | 用户可删除；不上传、不建社区 |
| 基础科普 | 只说明“怎样观察”，不把记录当作科学结论 |

非目标：相机识别、鸟类/水域扩展、排行榜、公开地图、社交动态、准确率或教育效果声明。

## 可信度与生态风险

- 用户观察：始终标注“个人观察，未鉴定”。
- 自动推测：首版不存在；未来只能给候选并说明不确定性。
- 社区内容：首版不存在；未来需审核、敏感物种位置模糊化与举报机制。
- 不采集照片、精确坐标或用户身份，避免对敏感生态点位造成干扰。

## 验证与成功标准

- 假设：新手可在 5 分钟内完成一次特征观察，且能理解记录不等于鉴定。
- 验证：用三种植物场景进行任务可用性访谈；询问用户能否区分“观察特征”和“物种结论”。
- 成功指标：完成率、误解率、删除路径可发现性；不以签到数量或使用时长推断学习效果。
