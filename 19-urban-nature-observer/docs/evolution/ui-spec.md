# UI契约 E1

沿用19号既有原生页面，不重新生成设计系统。当前有效组件说明引用 ../design/feature-observe-screen.md；旧MASTER的Web字体/橙色值不覆盖ArkUI实际资源。

任务：青年/亲子先选择一个植物特征观察，再保存和回访。线框顺序：标题/观察边界→四类任务/提示→四类粗略环境→可见特征→保存/反馈→本机历史/删除。再次观察回到顶部；返回键优先取消删除。

语义颜色见 entry/src/main/resources/{base,dark}/element/color.json。浅色canvas #F4FAF2、card #FFFFFF、active #E5F3E1、action #347C43、text_primary #173722、text_secondary #5B7561；深色对应 #122417/#1C3221/#244229/#86D592/#E5F7E7/#BDD7C1。系统HarmonyOS字体，无外部字体依赖；标题26fp、分组20fp、正文16fp以上；间距8/12/16、页面20、圆角14—20vp，最小按钮48vp，无装饰动效。

组件契约：选中同时有文字与颜色；busy禁用重复动作；失败用文字说明与恢复入口，不只用颜色；确认删除描述数量及不可恢复后果。读取失败不能显示虚构历史，保存成功才替换历史；坏档案沿用读取失败并禁止写入。

- UI-001→AC-004：本轮API24手机1256×2760、默认缩放、浅色、触摸完成闭环；截图检查分组清楚、文字完整、按钮可见且滚动可到达。
- UI-002→AC-004：选中标签实时刷新，互斥选项替换；保存/恢复/取消和确认删除具有可见状态变化。与自然观察主题一致的绿色资源保持一致。
- UI-003→后续发布：深色、大字号、平板、读屏焦点/外接键盘/无障碍对比度完整验收待执行；本轮不改变这些布局与组件，不将旧静态资源声称为已验收。
