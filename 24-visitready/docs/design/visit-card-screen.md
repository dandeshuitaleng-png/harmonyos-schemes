# 从容赴约 · 本机预访卡

主操作是保存一张离线私密预访卡。首屏依次呈现隐私边界、输入区、保存按钮和本机列表；正常、加载、空、读写错误/重试、禁用、编辑和只读摘要状态均有明确文字。编辑会把既有本地字段载入表单，取消编辑不会修改原卡；摘要可进入本地字段选择，逐项移除场所、时间、同行人或清单并即时预览，取消后回到只读摘要且不保存选择。该流程没有发送按钮或系统分享调用；零字段状态提示用户保留至少一个字段。本轮可保存可选的本地提醒日期；每张卡会明确显示“未创建系统提醒”，无论日期是否填写。由于未定义通知权限请求和调度语义，页面不调用通知 API、不请求权限；通知未接入或被拒绝时，用户仍可在卡片上看到日期并自行安排。附件取消和分享取消不阻断保存，因为这些系统能力尚未接入。手机/平板均为可滚动单列，所有状态不依赖颜色单独表达。
