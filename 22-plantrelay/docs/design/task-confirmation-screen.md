# 叶伴 · 本机任务确认与完成

页面继续使用可滚动单列：顶部说明只记录本地交接、不做诊断或同步；其后为新任务表单和任务列表。每张卡显示植物、任务和照护人，并明确处于“未确认”“已确认、待完成”或“已完成”之一。未确认任务可本地确认；确认后用户可填写完成时间和可选备注，保存后成为已完成。没有未确认任务或没有已完成任务时分别显示文字空态；完成信息不足时保存按钮禁用，取消不写入内容。任何本机写入失败都会保留当前输入，并显示针对上一次确认或完成动作的重试入口。卡片可打开导出前的本地字段选择：植物昵称、任务、确认状态默认包含，房间和完成时间按已有数据包含；照护人昵称与完成备注默认隐藏。所有字段移除时有文字提示，取消不保存选择，摘要只在屏幕中预览，不导出或发送。照片、提醒、真实导出、诊断、位置、网络、账号和同步不在本屏能力范围。手机与平板均保持单列滚动，状态有文字，不只依赖颜色。
