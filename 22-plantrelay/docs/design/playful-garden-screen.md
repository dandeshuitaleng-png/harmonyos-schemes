# SCR-01–04：可轻触的叶伴花园

> Route: pages/Index · Updated: 2026-09-07 · Status: implementation specification

## 1. 目标与边界

用户安排真实植物照护任务，明确谁已接手、何时完成。数据沿用 preferences leafmate/cards；记录数量称为“交接卡”，不把同名任务计成独立植物总数。每张卡可选 palette:number，默认 0，持久化各自的配色；旧记录无 palette 时仍可读取。

花园主操作“安排任务”；未接手任务主操作“确认接手”；已接手任务主操作“记录完成”；足迹以查看为主。核心流程不申请权限。Canvas 是装饰，不代表真实植物或健康状态；本机摘要只预览字段，不发送或导出。

## 2. 导航与结构

```text
pages/Index
├── 花园：真实交接概况 + 可轻触盆栽 + 三配色 + 安排任务
├── 交接：全部待办 / 待接手 / 已接手
└── 足迹：持久化成功的已完成任务
    子视图：新建 / 完成 / 本机摘要 / 关于
```

三个 tab 位于同一 Index 内；子视图用原生全页渐进表单，返回回原入口。表单不是初屏永久展开区，不必须绑定 modal。关于入口承载简短真实能力说明，不用长篇实现状态占据花园首屏。

| 优先级 | 区域 | ArkUI 与资源 | 交互 |
| --- | --- | --- | --- |
| P0 | 标题、真实状态、当前主操作 | Text/Button；text_primary/action_primary | 首屏或一次滚动可达 |
| P1 | 软陶花园 | ClayPlant Canvas；surface_garden 承托 | 点击摇摆、赤陶/鼠尾草/淡紫文字配色 |
| P1 | 交接卡 | List 或 Column；surface_card | 完整业务字段与当前状态操作 |
| P1 | 原生表单 | 可见 Text 标签 + TextInput/TextArea | 主动进入，保留输入 |
| P2 | 摘要字段 | Toggle/Checkbox 或文字按钮；surface_chip | 文字和显式选中标记 |
| P0 | 导航 | Tabs 或 Row/Button；surface_card | 图标配文字和选中状态 |

## 3. 新建、交接、足迹

新建字段：植物昵称（必填）、房间（可选）、要做的事（必填）、照护人昵称（必填）、软陶配色（默认赤陶）。字段有外部可见标签，placeholder 只作提示，不用示例值替代用户输入。保存到本机成功后返回，失败保留输入；取消不写入。

交接默认显示全部未完成任务。待接手为 confirmed 不为 true 且未完成，已接手为 confirmed 为 true 且未完成；两个状态都算待办。每张卡展示完整昵称、可选房间、任务、照护人及状态，不只用颜色区分。

确认接手写入成功后才变为“已接手 · 待完成”。点击记录完成进入全页表单：完成时间必填、备注可选，保存和取消均可达。只有 persist 成功后进入足迹、显示时间和备注，再播放一次庆祝与“已记下这次照护”反馈；失败不前移状态、不清空输入、不庆祝。

足迹只显示 completed 为 true 的真实记录。空态为“还没有完成记录”，可去交接；不根据点击次数、配色、等待时间产生记录。

## 4. 本机摘要

入口称“本机摘要”或“预览交接摘要”，说明仅在此预览。字段保留：植物昵称、房间、任务、照护人昵称、确认状态、完成时间、完成备注。照护人与备注默认不包含；未有内容的可选字段不制造占位数据。全部取消时提示至少选一个字段。返回/取消不会发送、导出或保存字段选择。

## 5. 状态模型

| 状态 | 显示和恢复 | 数据契约 |
| --- | --- | --- |
| 正常 | 真实卡片、明确状态操作 | 只渲染真实 cards |
| 初始加载 | 加载图示与正在读取文字；失败可重试 | 加载时不误显示空态 |
| 保存中 | 原内容与正在保存；禁重复提交 | 完成写入前不移卡、不庆祝 |
| 花园空态 | 单株装饰 + 安排第一件照护小事 | 图示不是样例任务 |
| 交接空态 | 当前没有待办；可安排或查看足迹 | 不把已接手任务排除在待办外 |
| 足迹空态 | 还没有完成记录；去交接 | 不补虚构时间线 |
| 读取错误 | 原因、重试读取 | 不覆盖原数据、不推定完成 |
| 写入错误 | 操作旁错误和再次保存 | 保留输入与原状态 |
| 禁用 | 说明缺哪个必填项或正在保存 | 补齐/保存结束恢复，不只变灰 |
| 权限拒绝 | 本轮核心流程无权限入口 | 不授权照片等也可用 |
| 离线 | 与正常相同，本机说明可查 | 不显示虚构同步状态 |
| 成功 | 正确状态文字和单次轻量庆祝 | 仅持久化成功触发 |
| 减少动效 | 即时静态反馈，换色仍可用 | 不影响业务记录 |

## 6. 布局、无障碍和动效

320vp 单栏、16vp 横向留白；主景随容器同比缩放，配色按钮可折行。常规手机主景约 220vp 高；导航留安全区和滚动内容尾部空间。600vp 以上内容居中限制宽度，可并排主景/概况。

150% 字号下卡片、标题、按钮随内容增高，不截断关键内容。长昵称、房间、任务、时间和备注换行；键盘开启仍可滚到保存/取消。系统返回回原入口，不伪装保存。

每个交互至少 48×48vp。任务按钮读屏名包含植物昵称和动作；导航、筛选、配色有文字与选中标记。Canvas 内部不暴露无意义节点，外层可玩入口说明“轻触盆栽，播放轻摇效果”。页内减少动效关闭运动反馈，但保留配色、静态选中和成功文案。

## 7. 必须实际验证

- 真实空态 → 新建 → 接手 → 完成时间/备注 → 写入成功 → 足迹 → 重启保留。
- 读取/新建/接手/完成写入失败 → 原状态与输入不丢 → 可重试；失败不庆祝。
- 摘要默认隐藏照护人与备注 → 显式开启 → 全不选 → 取消，无导出或发送。
- 各配色与点触 → 任务状态不变；减少动效 → 静态反馈；旧卡无 palette 可读。
- 320vp/手机/平板、深浅色、150% 字号、长文本、键盘、系统返回、读屏。

需要当前构建的花园/交接/足迹、空/错/展开表单深浅色截图。缺截图时 Visual / Accessibility 为 BLOCKED，不能从源码或构建成功宣称通过。旧 task-confirmation-screen.md 为历史单页说明，其布局由本版替代，真实状态约束保留。
