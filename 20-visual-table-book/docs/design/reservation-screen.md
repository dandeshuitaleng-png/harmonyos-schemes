# SCR-01: 演示桌位选择

> Route/entry: `pages/Index` · Status: Implemented（本地演示状态） · Updated: 2026-08-31

```text
[可视化订桌]
[演示模式：不连接真实餐厅]
[日期/人数选择]
[桌位平面图：可选、已选、不可选演示状态]
[创建本地预约草稿]
[草稿状态/取消]
```

| State | Trigger | Visible content | Recovery |
| --- | --- | --- | --- |
| Empty | 未选桌 | 演示桌位和选择说明 | 选择桌位 |
| Date empty | 未选演示日期 | 三个明确日期选项，创建按钮禁用 | 选择日期 |
| Selected | 选桌 | 桌号、座位数、演示状态 | 更换桌位 |
| Draft | 创建草稿 | “仅本机草稿，未发送给商家” | 取消草稿 |
| Unavailable | 选择不可用演示桌 | 不可用说明 | 选择其他桌 |

日期、人数或桌位任一变化都会取消当前本地草稿；草稿摘要必须展示当前选中的演示日期、桌位和人数。三个日期、人数、桌位均为演示静态状态，不查询真实库存或营业规则。

无障碍：每张桌位须读出桌号、座位数和状态；不只依赖颜色。平板可放大平面图，手机使用单列和可触达按钮。
