# drill-event: 创建演练事件

> Route/entry: `pages/Index` · Status: Implemented · Updated: 2026-08-30

## Purpose

- 用户目标：在离线演练中选择一种本地事件并创建记录，确认应用没有向外发送任何信息。
- 主操作：选择 `SOS 演练`、`避险点`、`道路障碍` 或 `物资点` 后，创建对应本机记录。
- 不得发生：不能声称已报警、已联系他人、已上传、已获得定位或已建立近场通信。
- 数据源：应用私有 Preferences 内的 `DrillRecord[]`；仅保存事件的本地标识、创建时间、固定类型、来源（本机演练）与审核状态（未提交）。定位、联系人、近场通信和确认上传仍属于后续切片。
- 权限：本切片不请求任何权限。

## Hierarchy and layout

1. 安全提示置顶：强调紧急情况使用系统电话。
2. 当前状态卡：说明离线演练与不上传边界。
3. 类型选择：四个有文字标签的原生按钮；已选项通过文字“已选择”与颜色共同表达。
4. 明确的主按钮：创建选定类型的本机记录。
5. 最近记录：空态解释首次操作；成功后显示日期时间、类型、来源、位置精度、审核状态和“仅本机保存，不会上传”。
6. 字段预览：用户可展开单条记录，查看未来导出/人工确认上传前会使用的本机字段；预览不生成文件、不联网，也不表示上传已可用。
7. 能力边界卡：未请求定位/联系人/短信；地图、近场、导出和上传仍未启用。
6. 首次进入先展示隐私说明；拒绝后仍可打开系统电话，但不读取演练记录。

紧凑手机使用可滚动的单列布局；平板沿用信息优先级并限制内容宽度。页面的语义色已映射至 `entry/src/main/resources/base/element/color.json`：`action_primary` 用于主操作，`surface_warning`/`text_warning` 用于警示，`surface_success`/`text_success` 用于已创建状态；每种状态都由文字而非颜色单独表达。

## State model

| State | Trigger | Visible content | Recovery |
| --- | --- | --- | --- |
| Loading | 页面出现 | “正在读取本机记录”且创建按钮不可用 | 自动完成读取 |
| Normal/empty | 首次读取完成且无记录 | 类型选择、“尚无本次演练记录”与主按钮 | 选择类型并创建记录 |
| Success | 写入成功 | 最近记录、成功说明、来源、精度和未提交状态 | 可继续创建另一类型、预览字段或清除 |
| Preview | 用户选择“查看字段预览” | 类型、时间、位置精度、来源、审核状态与外发边界 | 收起预览；后续单独实现导出或人工确认上传 |
| Offline | 始终 | “没有网络请求，也不会上传” | 无需恢复 |
| Permission unavailable | 始终 | “本切片未请求定位/联系人权限” | 后续能力接入前单独确认 |
| Disabled | 正在读取或未同意隐私说明 | 创建按钮不可用或不显示，解释当前原因 | 等待读取或返回隐私说明 |
| Error | Preferences 读取或写入失败 | 明确的本机存储错误与重试按钮 | 重试读取；不伪造已保存 |

## Accessibility and QA

- 读屏顺序：标题 → 紧急提示 → 演练状态 → 主按钮 → 最近记录 → 能力边界。
- 主按钮用文字说明行为；成功状态包含“已创建”文本。
- 需要在手机/平板、放大字号与深浅色模式下检查文字换行与按钮可达性。

## Token mapping

- `entry/src/main/resources/base/element/color.json` 与 `dark/element/color.json` 提供浅色和深色语义令牌：画布/卡片/状态/警示/成功表面，以及主要、次要、弱化、警示、成功文本。
- `action_primary` 与 `text_on_primary` 仅用于主操作；警示与成功状态仍由页面文字单独表达，不能仅依赖颜色。
