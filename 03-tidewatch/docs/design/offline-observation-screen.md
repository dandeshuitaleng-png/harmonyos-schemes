# TideWatch · 离线观察簿

Route：`pages/Index`。更新：2026-09-21。

## 页面与流程

隐私说明 → 观察簿 → 新建/编辑表单 → 保存回观察簿。
观察簿支持全文关键词检索及全部/有效期内/已过期筛选。筛选不改变存储数据。过期记录保留且只读；新情况重新创建。

表单：观察类型、标题2–40字、地点概述2–80字、现场描述5–500字、风险等级、有效期1/2/6/12/24小时。编辑不更改采集时刻和有效期。历史草稿没有内容时明确使用占位说明与未分类，不编造现场事实。

每张卡片：标题、类型/风险/有效性、地点、描述、来源、采集时间、有效至、尚无审核人、仅本机/未上传。有效记录可编辑；每条可删除，需二次确认。全量清除也需确认。

## 状态

| 状态 | 界面与行为 |
| --- | --- |
| 初次/隐私未知 | 显示说明，不读取观察 |
| 拒绝保存 | 隐藏记录，允许重新开启，历史不自动删除 |
| Loading/写入中 | 禁用冲突修改，等待落盘 |
| Empty | 引导创建真实观察，不自动插入示例数据 |
| 无搜索匹配 | 引导更换关键词或筛选，不伪装为空库 |
| 输入错误 | 表单保留，展示字段校验消息 |
| 数据损坏/读取失败 | 停止修改并允许重试，保留原数据 |
| 保存失败 | 保留输入，暂停修改，重新读取确认状态 |
| 过期 | 历史可查，不允许编辑旧观察刷新时间 |

页面切换回顶部，手动滚动列表保持正常；每30秒刷新到期显示，回前台也刷新。删除/取消输入均有确认。布局使用安全区域，主体最大宽度640vp。
