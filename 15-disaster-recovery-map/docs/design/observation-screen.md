# SCR-01: 用示例记录一次自然目击

> Route/entry: `pages/Index` · Status: Implementing · Updated: 2026-08-29

## Purpose

- 用户目标：留下一条仅保存在本机的自然目击线索。
- 主操作：`用示例记录`。
- 不得发生：不得声称已识别、已核验、已报警、已定位，或已接入相机。
- 数据源：Preferences 中的观察记录；仅在隐私同意后读写。
- 权限：本切片不请求任何权限。

## Hierarchy

```text
[地球 Online · 观测站]
[紧急/非应急说明 + 系统电话]
[示例现场图]
[用示例记录]
[我的观测 / 科普]
```

| State | Trigger | Visible content | Recovery |
| --- | --- | --- | --- |
| Privacy | 首次进入或主动查看 | 说明实际保存内容；同意或仅浏览 | 同意后进入主流程；拒绝仍可看科普 |
| Ready | 已同意或已拒绝 | 示例图与主操作 | 开始记录或打开系统电话 |
| Confirm | 使用示例照片 | 选择现象、可选地点/备注 | 保存或关闭 |
| Saved | 写入成功 | 已保存为未核验公众线索 | 回到观测站或查看列表 |
| Empty list | 无记录 | 尚无目击 | 用示例记录 |
| Storage error | 读写失败 | 错误与重试 | 重试；不伪造已保存 |

## Adaptation

- 手机单列滚动；平板限制内容最大宽度。
- 状态用文字表达，不只依赖颜色。
- 系统返回优先关闭说明层、记录层或隐私说明。
