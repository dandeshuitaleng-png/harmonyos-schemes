# 潮汐守望 / TideWatch

## 任务

建设面向沿海渔村、露营者和基层巡查员的离线风险观察簿：记录潮位异常、道路积水与避险物资，并用可信状态而非“实时预报”表达信息。

## 灵感与改造

- 研究来源：[Ocean Sentinels](https://github.com/Gowshik-S/Ocean-Sentinels) 的 Store-Carry-Forward 蓝牙风险上报。
- 改造重点：从全套灾害管理平台缩为“离线现场观察 + 管理员复核”，增加本地潮汐/封路公告来源标签。
- 同类核验：待复核；本轮无直接同类证据。

## MVP 与架构

- 巡查员离线创建照片、位置、风险等级和可见范围；居民只能查看已审核摘要。
- 本地数据库存原始证据；服务端只接受签名上传与审核状态变更。
- ArkTS 原生相机、定位和离线地图；分布式同步仅作为可选增强。

## 规则

- 不生成或传播未标来源的灾情结论；每条信息须显示采集时间、有效期和审核人角色。
- 不公开受保护地点、个人住址、救援队行动路线。

## 验收

- 无网创建、重启后仍可查看待传任务。
- 管理端拒绝后客户端能看到原因；居民端永不看到未审原件。
