# 组件规格：ClayPlant 软陶盆栽

> Category: Composite / Illustration · Updated: 2026-09-07 · Status: implementation specification

## 目的与边界

原生 Canvas 通过渐变、轮廓层叠与落影制造 3D 卡通观感，让花园可轻触、换色，在真实任务完成保存成功后温和庆祝。这不是 3D 模型、物理模拟、植物识别或健康可视化。透明画布不绘制 UI 文字，不当作真实植物照片。

用于花园主景和可选 compact 图。页面负责业务字段、可达文字和按钮；点触不修改 confirmed/completed，不增加卡片或足迹，不给养护建议。组件位置为 `entry/src/main/ets/components/ClayPlant.ets`。

## API

| 输入 | 类型 / 默认 | 行为 |
| --- | --- | --- |
| palette | number / 0 | 0 赤陶、1 鼠尾草、2 淡紫；只控制外观，页面负责每卡持久化 |
| happy | boolean / false | 笑眼与少量星点；仅对应成功反馈，不代表健康 |
| motionEnabled | boolean / true | false 时无摇摆运动，显示静态最终状态 |
| compact | boolean / false | 缩略版减少非必要细节 |
| pulse | number / 0 | 数值变化触发一次有限庆祝；父页面只在完成写入成功后更新 |
| onPlay | () => void | 点触回调供父级提供短反馈，不承担业务写入 |

## 形体和美术色

固定 viewBox 320×240，按容器等比例缩放并居中，不拉长盆栽。主景可约 220vp 高，compact 可在约 72vp 容器使用，实际尺寸由页面约束。

统一左上光源：椭圆盆口、圆润盆身、盆底接触阴影、上亮下暗渐变、不同朝向叶片、少量高光。表情友好且比例小，不遮挡主要形体。避免把重阴影铺满背景。

Canvas 使用集中定义的独立美术色板，参考软陶基调 #E8B294 赤陶、#E4EBD4 鼠尾草、#CABDE3 淡紫，并补充明暗层。固定绘画色不是交互控件颜色，不跟随系统文本高对比模式反相。Canvas 透明；外层承托面、控件、焦点和文本仍使用语义资源，深浅色边缘与层次需运行截图实测。

## 状态与交互

| 状态 | 视觉与交互 | 无障碍和恢复 |
| --- | --- | --- |
| Normal | 静止盆栽，轻触一次小幅摇摆；左右拖动最大约 18 度透视倾转，松手回正；不自动循环 | 外层按钮说明效果 |
| Pressed/focused | 外层按压反馈、焦点描边 | 至少 48vp 触控，支持常规激活 |
| Reduced motion | 无移动弹跳，点击静态反馈，换色即时 | 最终语义不变 |
| Success | 笑眼和有限星点，pulse 每次变化最多一次 | 页面同时用文字说明真实保存成功 |
| Compact | 简化形体 | 仅装饰时不额外获焦 |
| Disappear | 停止计时与待执行动画 | 再显示不补播旧庆祝 |

单阶段约 150–300ms，摇摆总计约 300–600ms。高频点击不得无限堆叠计时器；退出或关闭动效取消待执行动画并回到稳定姿态。

## 布局与可达性

Canvas 细节不逐个作为读屏节点，可玩入口由带标签的按钮或可达操作容器承托，名称说明点触效果。图示不传达唯一任务状态。320vp 和 150% 字号下画布不挤压外部文本。

配色控件由页面实现，带“赤陶 / 鼠尾草 / 淡紫”文字与选中标记，读屏知道选中名称。手动偏好或 AccessibilityKit 系统减少动态状态映射 motionEnabled=false；系统联动仍需真机实测后才能声明验收通过。
