# 织日 · 本机衣物照看卡

单列页面从上到下呈现数据边界、衣物表单与待照看列表。主操作是保存一张只包含用户填写文字的衣物卡：称呼、类别、状态、可选下一步日期、照看约定与可选准备项。每张卡可展开本机照看事件表单：用户填写事件类型、发生日期与可选备注后保存，时间线按新到旧显示；无事件、必填禁用、取消和保存失败后的再次保存均有文字状态。应用只记录用户说过的事件，不判断清洁、缝补或送修做法是否正确。加载、空态和读写失败/重试均有明确文字与下一步。日期无论是否填写都明确标注未创建系统提醒；照片、Picker、提醒、分享、服务卡片和网络没有接入，因此不会伪造相应成功状态。删除卡会关闭其事件表单；手机/平板使用可滚动单列，动作文本具备可读标签。
