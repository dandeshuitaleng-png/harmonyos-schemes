## 1. 产品目标与现状

面向沿海巡查员的离线观察簿，记录潮位异常、道路积水及避险物资。观察不等同于实时预报；居民未来只能读取服务端审核后的脱敏摘要。

现状为 ArkTS / ArkUI 单页应用，使用 Preferences 保存少量元数据，具有隐私选择和清除确认。缺少观察内容、编辑、分类、风险级别、筛选和自动化验证；过期数据在读取后从内存移除，下一次写入可能丢失历史；并发点击可能覆盖写入；损坏数据会被静默忽略。

## 2. 本轮实施范围：可用的离线文字观察簿

1. 新增观察表单：类型（潮位异常/道路积水/避险物资）、标题、地点概述、现场描述、风险等级（低/中/高/未评估）、有效期（1/2/6/12/24小时）。字段长度与必填验证，来源固定为现场巡查员本地记录，采集时间由系统生成。
2. 每条记录显示完整日期、有效期、来源、审核角色“尚无审核人”、仅本机可见、未上传；不伪造审核、同步或公告。
3. 新建和编辑均先完成持久化再更新列表。编辑保留原采集时间和截止时间，避免把旧观察变成新鲜数据。过期记录只读并保留，新的观察需重新创建。
4. 全部/有效期内/已过期筛选与文本搜索；到期定时刷新；支持单条删除及清空全部，两者均二次确认。
5. 读写期间禁用冲突操作；读取失败后禁止创建覆盖；损坏或不支持的存储格式不得自动替换为空数据。对原 JSON 数组与旧分隔行格式执行严格校验并兼容读取，下一次正常保存升级为带版本的格式。
6. 隐私说明与实际字段保持一致。拒绝保存后隐藏记录并关闭表单；撤回同意不默默删除历史，可重新同意后清除。
7. 维持现有深浅色语义资源、单列平板宽度与大按钮；处理加载、空白、无搜索结果、输入错误和存储错误。

本轮仍使用 Preferences，适合小型文字簿；上限200条以控制全量序列化成本。不能将此版本称为照片证据库或具备服务端审核的完整系统。

## 3. 完整产品后续阶段

### P1：原始证据与本地数据库

迁移到关系型数据库，Observation、Attachment、Outbox 分表并用事务维护。照片由系统相机/选择器获取后复制到应用私有目录，持久化附件路径；定位需按需申请权限，拒绝时允许手动地点描述。保存坐标精度、来源、采集时刻和有效期，精确坐标不进入公共摘要。迁移需备份和回滚测试，验证存储不足、附件丢失和重启恢复。离线地图需先落实授权地图与离线数据，不以假地图替代。

### P2：签名上传与复核闭环

先定义接口和威胁模型：认证身份由服务端校验；原始证据上传签名覆盖正文摘要、时间戳和随机值；服务端防重放与幂等。客户端 Outbox 状态为 queued/uploading/retry/received，审核状态为 pending/approved/rejected/withdrawn，两套状态独立。断网/超时保留任务，指数退避；只有服务端回执可改变审核结果。

管理员必须有真实授权，拒绝需填写原因；保存审核人角色、审核时间、摘要、有效期和审计记录。驳回原因返回巡查端；修订创建新版本重新审核。审批撤回与到期均下架居民摘要。不得用本地角色切换冒充服务端鉴权。

### P3：居民端与来源公告

居民 API 仅输出经过审核的字段白名单，排除原图、精确坐标、原始备注、个人住址与受保护地点。无有效公告时显示空态；来源公告标识发布单位、原始链接、发布时间和有效期；没有已核验的数据源就不显示“实时潮汐”。测试越权访问、缓存到期、撤回同步和误发布回滚。

### P4：发布

确认主体与隐私文本；配置本机调试签名；在真实手机/平板进行离线、杀进程重启、大字体、深浅色和无障碍验收。仅使用应用对应的签名资料，不复制其他项目证书。最后进行签名包构建、安装与升级迁移测试、发布说明和应用市场材料整理。

## 4. 开发与验证流程

每轮：读取约束 → 明确用户流程和字段 → 实现领域规则 → 接入存储 → 接入界面 → 自动化测试 → DevEco assembleHap → 真机用例 → 记录证据与限制。

本轮自动化覆盖必填/长度/风险枚举、日期边界、旧格式迁移、损坏数据拒绝、重复ID、过期保留、编辑不延长有效期、保存失败恢复与串行写入。构建验证真实 ArkTS 编译，不以普通 TypeScript 测试替代。未配置签名时标记真机验证未完成，不能沿用历史日志充当本轮证据。

## 5. 验收用例

- 首次启动同意后创建真实文字观察，强制退出再启动后字段保持一致。
- 必填空白、超长内容或非法值不能保存；连续点击保存只产生一条。
- 编辑保留采集/截止时间；过期记录进入历史，创建新记录后旧记录仍存在。
- 搜索和筛选只改变显示结果，不改变保存集合。
- 存储读取失败或格式损坏时阻止覆盖；保存失败保留表单并显示错误。
- 单条/全部删除必须确认，取消保持不变；持久化失败不能先从UI移除。
- 隐私拒绝后不读取观察；重新同意可恢复本机历史。
- 所有观察均显示尚无审核人、仅本机与未上传，不出现已审核公告。
