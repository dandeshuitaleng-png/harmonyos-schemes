# 微光习惯 / GentleSteps

## 产品目标

提供非竞争、无连续打卡惩罚的微习惯练习：喝水、伸展、离屏、联系朋友。用户可选择用一个抽象植物成长来可视化坚持。

## 灵感与边界

- 来源：[DinoJourney](https://github.com/matheusmaldaner/DinoJourney) 的低压力陪伴式任务设计。
- 不做心理测评、诊疗或以虚拟成长诱导消费；公开鸿蒙同类待核验。

## MVP 与交互

- 一天最多三个用户主动选择的微任务；完成/跳过都可记录理由。
- 卡片只显示下一项和完成按钮；动画尊重减少动态设置。
- 数据本地保存，导出为个人回顾而非社交排名。

## 验收

- 可离线设置、完成、跳过和撤销；150% 字号下操作完整。
- 禁止连续天数归零、付费解锁或用健康指标评判用户。
