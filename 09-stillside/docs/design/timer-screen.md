# SCR-01: 静默练习计时

> Route/entry: `pages/Index` · Status: Implementing · Updated: 2026-08-29

## Purpose

- 用户目标：自主完成一段短暂的安静练习。
- 主操作：选择 2/5/10 分钟后“开始安静练习”。
- 不得发生：不得把计时结果显示为心理状态、治疗效果或与他人共同在线；不申请任何权限。

## Hierarchy

```text
[隐私说明：同意或仅计时]
[静伴空间]
[非医疗说明 + 系统电话]
[时长选择]
[剩余时间/当前状态]
[开始、暂停或结束]
[可选：保存/清除本机练习次数]
```

| State | Trigger | Visible content | Recovery |
| --- | --- | --- | --- |
| Policy | 首次进入或主动查看 | 数据范围、同意 / 仅计时 | 同意后进入练习；拒绝后不计次数 |
| Ready | 同意或拒绝后 / 结束后 | 时长选项与开始按钮 | 选择时长 |
| Running | 开始 | 剩余时间、暂停和结束 | 暂停或结束 |
| Paused | 暂停 | 剩余时间与继续 | 继续或结束 |
| Completed | 倒计时到零 | 完成本次练习，非医疗结论 | 开始新的练习 |
| Storage error | 读取/写入次数失败 | 未保存提示与重试 | 重试或关闭保存 |
| Dialer error | 系统电话无法打开 | 改用系统电话应用的说明 | 退出后使用系统电话 |

## Adaptation and accessibility

- 手机为单列滚动；平板保留同一顺序并增大内容列宽。
- 状态用文字和图标/标题表达，不只依赖颜色；控制顺序为说明、时长、状态、主操作、保存设置。
- 无动画依赖：计时文字本身就是状态反馈；系统返回会停止当前会话，且不会自动保存未完成记录。
