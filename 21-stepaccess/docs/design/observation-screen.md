# 首页：本地步道观察

> 路由：`pages/Index` · 状态：Implemented（RDB 持久化待真机验证） · 更新：2026-08-30

## 目的与边界

- 用户目标：记录一个障碍、一种出行情境和本人的通行感受。
- 主操作：创建仅保存在本机关系型数据库的未审核观察。
- 禁止结果：不请求定位、相机或网络；不产生真实审核、评分、导航或路线推荐。
- 数据源：应用私有 RDB 中的手动选择与创建时间；不存储位置、照片、诊断、账号或持续轨迹。记录保留至用户主动删除。
- 权限：无。

## 信息层级与组件

```text
标题与一句话任务
未审核 / 无权限 / 本机保存边界卡
障碍类型选择组
辅助器具或出行情境选择组
本人通行感受选择组
禁用原因或创建按钮
当前会话观察卡与删除入口
```

| 优先级 | 内容 | ArkUI | 交互 |
| --- | --- | --- | --- |
| P0 | 未审核和非认证边界 | `Column` + `Text` | 始终可见 |
| P0 | 三组选择 | `ForEach` + `Button` | 单组选一个，文字显示已选 |
| P0 | 创建观察 | `Button` | 三组完整后启用 |
| P1 | 本机观察列表 | `ForEach` + `Column` | 单条删除并重新读取本机库 |

## 状态模型

| 状态 | 可见内容 | 恢复 / 下一步 |
| --- | --- | --- |
| 空态 | 三组未完成，主按钮禁用 | 依次完成三个选择 |
| 编辑态 | 选中项有“已选择”文字 | 可继续选择或创建 |
| 加载 | 读取或写入本机库时显示读取提示，创建按钮不可用 | 自动完成或显示错误 |
| 空态 | 尚无本机观察 | 完成三项选择并创建 |
| 成功态 | 按时间倒序展示 `仅自己可见 · 未经审核` 本机观察 | 删除并重新记录 |
| 错误 | 本机库读写或删除失败提示与重试 | 重试读取本机观察 |
| 离线 | 与正常状态相同 | 无网络依赖 |
| 权限不可用 | 与正常状态相同 | 使用手动选择，不请求权限 |

## 验收

- 构建：结构、资源引用、ArkTS 类型检查和 HAP 打包。
- 运行：选择、重新选择、禁用恢复、RDB 创建、读取、删除和重启恢复。
- 可访问性：读屏顺序、选中状态文字、150% 字号、Light/Dark。
- 视觉：手机和平板当前截图；没有运行证据时不得宣称视觉通过。
